# Karier dan Lowongan Pengajar Kodie (`/karier`)

## Bergabung Menjadi Pengajar Paruh Waktu di Kodie

Kodie membuka kesempatan kerja paruh waktu yang fleksibel bagi **mahasiswa aktif, lulusan baru, dan pencari kerja** di bidang teknologi untuk mengajar siswa **TK B, SD, SMP, dan SMA** secara daring.

### Keuntungan Mengajar di Kodie
- **Jadwal Fleksibel:** Pengajar bebas membuka kelas dan menentukan jadwal mengajarnya sendiri.
- **Sepenuhnya Daring:** Dapat mengajar dari mana saja cukup dengan laptop dan koneksi internet stabil.
- **Materi Sudah Siap (Teaching Playbook):** Setiap sesi sudah dilengkapi Teaching Playbook langkah demi langkah sehingga pengajar pemula pun bisa mengajar dengan standar yang sama.
- **Skema Bagi Hasil 30%–40% per Sesi:** Honor dihitung otomatis begitu laporan sesi dikirim sebesar **30%** dari pendapatan paket berbayar (dibagi jumlah sesi), dan naik menjadi **40%** untuk peserta paket yang mendaftar memakai **kode referral** milik pengajar tersebut. Dashboard pengajar juga menampilkan **Perkiraan Bagi Hasil** untuk kelas yang sedang berlangsung.
- **Kode Referral & Profil Profesional:** Pengajar terverifikasi bisa membuat kode referral unik (memberikan diskon **5%** bagi siswa sekaligus bonus bagi hasil **40%**), serta menampilkan riwayat **pengalaman** dan **sertifikat** di profil publik pengajar.
- **Portofolio & Pengalaman Nyata:** Membangun pengalaman mengajar dan komunikasi teknis untuk karier di industri IT.

## Enam Posisi Pengajar yang Dibuka di `/karier`

1. **Pengajar Coding Dasar** (`/karier/pengajar-coding-dasar`) — Bidang Software untuk siswa SD (kelas 3–6). Materi: Scratch, logika dan algoritma, *computational thinking*.
2. **Pengajar Python** (`/karier/pengajar-python`) — Bidang Software untuk SMP–SMA. Materi: Python dasar (variabel, perulangan, fungsi, list, dictionary), struktur data, proyek mini.
3. **Pengajar Pengembangan Web** (`/karier/pengajar-web`) — Bidang Software untuk SMP–SMA. Materi: HTML, CSS, dan JavaScript dasar.
4. **Pengajar Jaringan Komputer** (`/karier/pengajar-jaringan`) — Bidang Jaringan untuk SMP–SMA. Materi: dasar jaringan (OSI/TCP-IP), alamat IP dan subnet, simulasi Cisco Packet Tracer.
5. **Pengajar IoT dan Arduino** (`/karier/pengajar-iot`) — Bidang IoT untuk SMP–SMA. Materi: Arduino (C/C++), sensor dan aktuator, simulasi Wokwi atau Tinkercad (tanpa perlu membeli alat fisik).
6. **Pengajar AI dan Data** (`/karier/pengajar-ai-data`) — Bidang AI & Data untuk SMA. Materi: analisis data dengan Python (`pandas`, `matplotlib`), visualisasi data, dan dasar *machine learning*.

## Lima Langkah Melamar Menjadi Pengajar

1. **Pilih posisi** di `/karier` dan baca rincian tugas serta syaratnya.
2. **Buat akun pengajar** di halaman posisi tersebut (`/karier/[slug]`) dengan mengisi data diri, kampus, jurusan, status kerja, dan bidang keahlian (bidang posisi otomatis terpilih).
3. **Lengkapi berkas** di `/mengajar/profil`: unggah foto profil, kartu identitas (**KTP atau KTM**), dan **SKCK**, serta pilih program yang ingin diajar.
4. **Wawancara singkat** bersama tim Admin Kodie.
5. **Mulai mengajar:** Setelah diverifikasi Admin (status `terverifikasi`), pengajar bisa langsung membuka kelas baru dan mengajar.
