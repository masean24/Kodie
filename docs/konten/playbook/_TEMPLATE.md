# Teaching Playbook (template)

Satu file untuk setiap kombinasi program, level, dan nomor sesi. Contoh nama file:

- `coding-dasar-l1-s1.md`
- `kelas-reguler-l1-s2.md`
- `simulasi-jurusan-it-l1-s3.md`

Isi file dipakai di kolom `konten_md` tabel `playbook` (PRD F9). Untuk demo, minimal sesi 1 dan 2 setiap program harus terisi lengkap.
