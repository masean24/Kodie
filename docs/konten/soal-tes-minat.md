# Soal tes minat jurusan IT (template)

Diisi oleh anggota tim yang memegang konten. Setelah final, isi file ini dipakai untuk `seed.sql` (backend) dan data mock (frontend). Aturannya ada di PRD F4.

## Aturan

- Ada 12 soal, masing-masing dengan 4 opsi.
- Setiap opsi memberi bobot 0–3 ke satu atau lebih bidang: **software**, **jaringan**, **iot**, **ai_data**.
- Bahasa harus bisa dipahami siswa SMP kelas 9 dan SMA. Hindari istilah teknis tanpa penjelasan.
- Sebaiknya total bobot maksimal tiap bidang di seluruh soal kurang lebih seimbang, supaya hasilnya tidak condong ke satu bidang.
- Rumus persentase (asumsi, lihat `docs/KEPUTUSAN.md`): skor bidang ÷ jumlah skor keempat bidang × 100, dibulatkan ke bilangan bulat.
- Jika nilainya seri, prioritasnya Software, Jaringan, IoT, lalu AI & Data.

| Opsi | Teks | software | jaringan | iot | ai_data |

| C | Merakit atau memprogram alat seperti lampu otomatis | 0 | 0 | 3 | 0 |
| D | Mencari pola dari data, misalnya statistik game favorit | 0 | 0 | 0 | 3 |
